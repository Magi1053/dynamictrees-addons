# Dynamic Trees for [Let's Do] Vinery

Grow **[Let's Do] Vinery** orchards the Dynamic Trees way. Apple and dark cherry trees become living species with seeds, gradual growth, and worldgen that cancels the old static trees.

## Features

- Dynamic Trees species for Vinery apple and dark cherry trees
- Worldgen cancellers so Vinery biomes / features favor growing trees
- Sapling and loot alignment so players get Dynamic Trees seeds instead of dead-end primitive saplings
- Wandering winemaker trade tweaks that sell the matching Dynamic Trees seeds
- Optional EMI integration that hides blocked primitive saplings from the recipe viewer

## Included trees

- Apple (Vinery apple tree → Dynamic Trees apple / apple-oak seed flow)
- Dark Cherry

## Requirements

| Dependency | Required |
|---|---|
| Minecraft 1.21.1 | Yes |
| NeoForge | Yes |
| [Dynamic Trees](https://modrinth.com/mod/dynamictrees) | Yes |
| [Let's Do - Vinery](https://modrinth.com/mod/lets-do-vinery) | Yes |
| [EMI](https://modrinth.com/mod/emi) | Optional |

## Notes

- This project is **Vinery only**. Meadow trees ship as a separate mod: [Dynamic Trees for Let's Do Meadow](https://modrinth.com/organization/viberanium).
- Requires a NeoForge 1.21.1 instance with Dynamic Trees installed.
- If you previously used a combined Vinery + Meadow jar, install both standalone mods going forward.
