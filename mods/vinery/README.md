# Dynamic Trees for [Let's Do] Vinery

Dynamic Trees addon for [Let's Do] Vinery — apple and dark cherry trees that grow over time.

Adds Dynamic Trees species for Vinery's apple and dark cherry trees, with matching seeds, leaves, and worldgen cancellers so static Vinery trees are replaced by growing DT trees. Includes trade/loot tweaks so villagers and saplings line up with DT seeds.

## Requirements

- Minecraft 1.21.1
- NeoForge
- Dynamic Trees
- [Let's Do] Vinery

## Optional

- EMI

## Build

```bash
./gradlew -p mods/vinery build
```

## Publish

Tag `vinery/v1.0.18` on the monorepo to publish this module to Modrinth.

Set `modrinth_project_id` in `gradle.properties` after creating the Modrinth project.
