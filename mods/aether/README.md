# Dynamic Trees for The Aether

Dynamic Trees addon for The Aether and Deep Aether — growing skyroot, golden oak, and Deep Aether woods.

Adds Dynamic Trees species and worldgen for The Aether and Deep Aether trees, including skyroot, golden oak, crystal skyroot, roseroot, blue roseroot, conberry, cruderoot, yagroot, and sunroot. Replaces static trees with growing DT trees and blocks planting the original saplings where DT seeds are used instead.

## Requirements

- Minecraft 1.21.1
- NeoForge
- Dynamic Trees
- The Aether
- Deep Aether

## Optional

- EMI

## Build

```bash
./gradlew -p mods/aether build
```

## Publish

Tag `aether/v1.0.17` on the monorepo to publish this module to Modrinth.

Set `modrinth_project_id` in `gradle.properties` after creating the Modrinth project.
