# Dynamic Trees for The Aether

Bring **Dynamic Trees** into **The Aether** and **Deep Aether**. Static sky-island trees become living, growing species with Dynamic Trees seeds, branches, and worldgen.

## Features

- Growing Dynamic Trees species for Aether and Deep Aether woods
- Worldgen integration so islands feel alive instead of stamped with static trees
- Primitive saplings that are replaced by Dynamic Trees seeds (with optional EMI cleanup)
- Soil support so trees can establish on Aether ground blocks during generation

## Included trees

**The Aether**

- Skyroot
- Golden Oak
- Crystal Skyroot

**Deep Aether**

- Roseroot
- Blue Roseroot
- Conberry
- Cruderoot
- Yagroot
- Sunroot

## Requirements

| Dependency | Required |
|---|---|
| Minecraft 1.21.1 | Yes |
| NeoForge | Yes |
| [Dynamic Trees](https://modrinth.com/mod/dynamictrees) | Yes |
| [The Aether](https://modrinth.com/mod/aether) | Yes |
| [Deep Aether](https://modrinth.com/mod/deep-aether) | Yes |
| [EMI](https://modrinth.com/mod/emi) | Optional (hides replaced saplings in EMI) |

## Notes

- Designed for NeoForge 1.21.1 packs that already use Dynamic Trees in the Overworld.
- Install alongside Dynamic Trees; this addon does not replace the base mod.
- Deep Aether woods are included so mixed Aether + Deep Aether worlds stay consistent.
