# Dynamic Trees for Spectrum

Dynamic Trees addon for Spectrum's colored trees — all 16 dye colors as growing DT species.

Replaces Spectrum's static colored tree patches with Dynamic Trees species for every dye color. Keeps Spectrum-style rarity/worldgen feel while trees grow and can be farmed with DT seeds. Works with Revelationary cloaking for progression-gated tree looks.

## Requirements

- Minecraft 1.21.1
- NeoForge
- Dynamic Trees
- Spectrum
- Revelationary

## Optional

- EMI

## Build

```bash
./gradlew -p mods/spectrum build
```

## Publish

Tag `spectrum/v1.0.19` on the monorepo to publish this module to Modrinth.

Set `modrinth_project_id` in `gradle.properties` after creating the Modrinth project.
