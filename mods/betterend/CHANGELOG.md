# Changelog

## 1.0.1

- Lucernia dynamic leaves now use BetterEnd's numbered leaf models instead of a missing `lucernia_leaves` model.
- Cancel BetterEnd tree and bush features in BetterEnd biomes (they are not in `#minecraft:is_end`), and hard-cancel those feature classes so vanilla canopies no longer generate and drop their leaves.
- End species use `preferred_climate` instead of removed `environment_factors`, and no longer rot.

## 1.0.0

- Initial Modrinth release: Dynamic Trees species for BetterEnd dragon tree, lacugrove, lucernia, pythadendron, and tenanea.
- End soils, worldgen replacement, and primitive sapling blocking.
