# Dynamic Trees for BetterEnd

Give **BetterEnd** forests a Dynamic Trees makeover. End canopy trees become growing species with seeds, soils, and worldgen that replaces static BetterEnd tree features.

## Features

- Dynamic Trees species for five BetterEnd trees
- End soil properties for shadow grass, moss, dust, pink moss, rutiscus, and chorus nylium
- Worldgen support that cancels BetterEnd tree/bush features in the End and plants living trees
- Primitive sapling blocking so players plant Dynamic Trees seeds instead
- Optional EMI integration that hides replaced saplings from the viewer

## Included trees

- Dragon Tree
- Lacugrove
- Lucernia
- Pythadendron
- Tenanea
