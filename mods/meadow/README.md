# Dynamic Trees for [Let's Do] Meadow

Dynamic Trees addon for [Let's Do] Meadow — pine, orange pine, and alpine birch.

Adds Dynamic Trees species for Meadow's pine, orange pine, and alpine birch trees, with DT seeds and worldgen support so Meadow biomes grow living trees instead of static ones.

## Requirements

- Minecraft 1.21.1
- NeoForge
- Dynamic Trees
- [Let's Do] Meadow

## Optional

- EMI

## Build

```bash
./gradlew -p mods/meadow build
```

## Publish

Tag `meadow/v1.0.0` on the monorepo to publish this module to Modrinth.

Set `modrinth_project_id` in `gradle.properties` after creating the Modrinth project.
