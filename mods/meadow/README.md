# Dynamic Trees for [Let's Do] Meadow

Give **[Let's Do] Meadow** forests a Dynamic Trees makeover. Alpine pines and birch become growing species with seeds and worldgen that fits Meadow biomes.

## Features

- Dynamic Trees species for Meadow pine, orange pine, and alpine birch
- Worldgen support so Meadow landscapes grow living trees instead of static placements
- Primitive sapling blocking so players plant Dynamic Trees seeds instead
- Optional EMI integration that hides replaced saplings from the viewer

## Included trees

- Pine
- Orange Pine
- Alpine Birch

## Requirements

| Dependency | Required |
|---|---|
| Minecraft 1.21.1 | Yes |
| NeoForge | Yes |
| [Dynamic Trees](https://modrinth.com/mod/dynamictrees) | Yes |
| [Let's Do - Meadow](https://modrinth.com/mod/lets-do-meadow) | Yes |
| [EMI](https://modrinth.com/mod/emi) | Optional |

## Notes

- This project is **Meadow only**. Vinery trees ship as a separate mod: [Dynamic Trees for Let's Do Vinery](https://modrinth.com/organization/viberanium).
- Requires NeoForge 1.21.1 and Dynamic Trees.
- If you previously used a combined Vinery + Meadow jar, install both standalone mods going forward.
