# Dynamic Trees Rubber

A Dynamic Trees rubber species with latex tapping and early-game rubber items.

Adds a Dynamic Trees rubber tree that can be tapped for latex, plus related rubber items and blocks. Optional hooks for Create, TFMG, and other rubber consumers when those mods are present.

## Requirements

- Minecraft 1.21.1
- NeoForge
- Dynamic Trees

## Optional

- Create, TFMG, and related rubber/compat mods

## Build

```bash
./gradlew -p mods/rubber build
```

## Publish

Tag `rubber/v1.0.45` on the monorepo to publish this module to Modrinth.

Set `modrinth_project_id` in `gradle.properties` after creating the Modrinth project.
