# Changelog

## 1.0.52

- Added the full vanilla rubber wood set: wood, stairs, fence, fence gate, door, trapdoor, button, pressure plate, signs, hanging signs, boat, and chest boat.
- Fixed client reload crash from duplicate boat/chest-boat model-layer registration (vanilla already covers enum-extended `Boat.Type` values).
- Optional soft dependencies on Quark, Every Compat, and Moonlight so rubber chests can generate when those mods are present; this mod does not ship chests.
- Dropped unused soft dependencies on other Dynamic Trees packs and removed dead registration helpers.
- Simplified item/block registration and tapping helpers.

## 1.0.51

- Tag rubber seeds, saplings, and leaves for recipe and block compatibility, including Create pulp processing.

## 1.0.50

- Rubber planks and slabs now count as a wood type.

## 1.0.49

- Added rubber slabs, crafted from rubber planks.
- Stripped rubber wood counts as a burnable log.

## 1.0.48

- Fixed cutting speed

## 1.0.47

- EMI Information page for collecting Raw Latex.

## 1.0.46

- Renamed Create's Mechanical Belt advancement from "Kelp Drive" to "Rubberᵗᵐ Drive".

## 1.0.45
